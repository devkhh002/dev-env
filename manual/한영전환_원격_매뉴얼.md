# 새 Mac 셋팅 매뉴얼 (한/영 + 원격)

> 작성일: 2026-09-15 · 실제로 셋팅해서 동작 확인한 구성 기준
> 순서대로 따라 하면 됩니다. 원격을 안 쓰면 **1장만** 하면 끝.

---

## 최종 구성 한눈에 보기

| 구분 | 방식 |
|---|---|
| Mac 한/영 | 구름입력기 (두벌식 ↔ 로마자), 단축키 Shift+Space |
| 원격 한/영 | Mac: Karabiner (원격 창에서 Shift+Space → Option+Space)<br>Windows: AutoHotkey (Option+Space → 한/영 키) |
| 원격 접속 | Tailscale(VPN) + Moonlight(Mac) / Sunshine(Windows), 보조로 크롬 원격 데스크톱 |

**쓰지 않는 것:** `Mac한영전환.app`, Mac-install v2~v5 스크립트, macOS 기본 입력기 전환

---

## 1장. Mac 한/영 전환 (구름입력기)

### 1-1. 설치
1. https://gureum.io 에서 다운로드 → pkg 실행해서 끝까지 설치
2. **로그아웃 후 다시 로그인** (안 하면 입력 소스 목록에 안 나옴)

> 구름입력기는 **응용 프로그램 폴더에 안 보이는 게 정상**입니다. `/Library/Input Methods`에 설치됩니다.

### 1-2. 입력 소스 추가
**시스템 설정 → 키보드 → 텍스트 입력 → 입력 소스 "편집..."**

1. **+** → 언어 **한국어** → 구름 **두벌식** 추가
2. **+** → 언어 **영어** → 구름 **로마자** 추가
3. 기본 **한국어 2벌식**은 선택 후 **−** 로 삭제
4. ABC는 안 지워져도 그대로 두면 됨 (선택만 안 하면 됨)
5. 같은 화면에서 **"문서의 입력 소스로 자동으로 전환" 끄기** → 완료

> ⚠️ 주의: 한국어 목록의 **"한글 로마자"는 넣지 말 것.** 영문 자판이 아니라 발음대로 한글을 만드는 입력기라 `ㄸ` 같은 이상한 글자가 나옵니다. 영문은 반드시 **영어 목록의 "로마자"**.

### 1-3. macOS 기본 단축키 끄기
**시스템 설정 → 키보드 → "키보드 단축키..." 버튼 → 왼쪽 목록 "입력 소스"**

- **이전 입력 소스 선택** → 체크 해제
- **입력 메뉴에서 다음 소스 선택** → 체크 해제
- 완료

> 이게 켜져 있으면 macOS가 Shift+Space를 먼저 가져가서 구름 설정이 안 먹고, ABC까지 3개를 돌아가며 바뀝니다.

### 1-4. 구름 단축키 지정
메뉴 막대 입력 메뉴 → **구름 환경설정**

- **한글/로마자 바꾸기 단축키** 칸 클릭 → **Shift+Space** 입력
  (칸에 안 들어가면 **Fn+Shift+Space**)
- **오른쪽 키 언어 전환**: 안 쓰면 **사용 안 함**

### 1-5. 확인
메뉴 막대에서 **구름 두벌식** 한 번 선택 → Shift+Space로 **두벌식 ↔ 로마자 두 개만** 오가면 정상.

## 2장. 원격 접속 (필요할 때만)

### 2-1. Tailscale (Mac, Windows 둘 다)
1. https://tailscale.com/download 에서 설치
2. 두 기기 모두 **같은 계정**으로 로그인
3. Windows PC의 IP(`100.x.x.x`)는 트레이 Tailscale 아이콘 또는 https://login.tailscale.com/admin/machines 에서 확인

### 2-2. Moonlight 설치 (Mac) — DMG 주의
1. https://github.com/moonlight-stream/moonlight-qt/releases 에서 `.dmg` 다운로드
2. dmg 열기 → **Moonlight 아이콘을 Applications 폴더로 끌어다 놓기**
3. ⚠️ **dmg 창 안의 Moonlight를 더블클릭해서 실행하지 말 것**
4. 바탕화면 디스크 아이콘 **우클릭 → 추출**
5. 다운로드 폴더의 dmg 파일 삭제
6. **Finder → 응용 프로그램 → Moonlight**로 실행, Dock 아이콘 우클릭 → 옵션 → Dock에 유지

> dmg 안에서 실행하면: 실행할 때마다 바탕화면에 디스크가 생기고, 추출 시 "사용 중", Dock에 Moonlight 2개가 생깁니다.
> 설정(페어링, 해상도 등)은 앱이 아니라 사용자 계정에 저장되므로 재설치해도 유지됩니다.

### 2-3. Windows PC (호스트)
`Windows-install-v1.zip` 압축 풀고 **install-Windows-v1.bat 더블클릭** → 관리자 권한 "예"
→ Sunshine, Tailscale, AutoHotkey, 한/영 스크립트가 자동 설치됨

수동으로 할 경우 한/영 스크립트 내용 (`shell:startup` 폴더에 `hangul.ahk`로 저장):
```
#Requires AutoHotkey v2.0
!Space::Send "{vk15}"
```

### 2-4. 페어링
1. Windows PC 브라우저에서 `https://localhost:47990` 접속 (경고 뜨면 고급 → 이동)
2. 처음이면 관리자 계정 생성
3. Mac Moonlight에서 **+** → Windows PC의 `100.x.x.x` 입력 → PIN 4자리가 뜸
4. Windows 웹 페이지 상단 **PIN** 메뉴에 그 숫자 입력 → Send

> Sunshine은 PIN 입력창을 화면에 띄워주지 않습니다. **반드시 웹 페이지에서** 입력.

### 2-5. Moonlight 화질 설정 (PC 목록 화면 오른쪽 위 톱니바퀴)
| 항목 | 값 |
|---|---|
| 해상도 | 1440p (또는 네이티브) |
| 비트레이트 | 40 Mbps (80 올려도 체감 차이 적고 데이터만 더 씀) |
| 비디오 코덱 | **자동** (H.265로 바꾸면 글자 뭉개짐) |
| Enable YUV 4:4:4 | 켜기 |

- 원격 화면에서 설정으로 나가기: **Control+Option+Shift+Q**
- 흰 글씨가 회색 느낌이면: Windows 쪽 **HDR 끄기**, 그래픽카드 색 범위 **전체(Full)**
- 휴대폰 데이터로 접속할 땐 크롬 원격이 유리 (Moonlight는 데이터 많이 씀)

## 3장. 원격 한/영 (Karabiner-Elements)

### 3-1. 설치
1. https://karabiner-elements.pqrs.org/ 에서 설치
2. 설치 중 뜨는 **입력 모니터링 / 시스템 확장 허용**은 전부 허용
   (시스템 설정 → 개인정보 보호 및 보안 에서 허용 버튼이 뜨기도 함)

### 3-2. 규칙 추가
Karabiner-Elements → **Complex Modifications → Add your own rule** → 아래 붙여넣고 저장

```json
{
    "description": "Moonlight + Chrome Remote: Shift+Space -> Option+Space",
    "manipulators": [
        {
            "conditions": [
                {
                    "bundle_identifiers": [
                        "^com\\.moonlight-stream\\.Moonlight$",
                        "^com\\.google\\.Chrome\\.app\\.cmkncekebbebpfilplodngbpllndjkfo$"
                    ],
                    "type": "frontmost_application_if"
                }
            ],
            "from": {
                "key_code": "spacebar",
                "modifiers": { "mandatory": ["shift"] }
            },
            "to": [
                {
                    "key_code": "spacebar",
                    "modifiers": ["left_option"]
                }
            ],
            "type": "basic"
        }
    ]
}
```

- **이 규칙 하나만** 둘 것. Mac용 한/영 규칙(F18 등)은 넣지 않음 → Mac 한/영은 구름이 담당
- 원격이 안 먹으면: **Karabiner-EventViewer → Frontmost Application**에서 해당 앱 창을 클릭해 실제 Bundle ID 확인 후 규칙의 값 수정

### 3-3. 사용
- 원격 창 안에서 **Shift+Space** → Windows 한/영 전환
- 원격 창 밖에서는 구름입력기가 Mac 한/영 전환

## 4장. 문제 해결 메모

| 증상 | 원인 / 해결 |
|---|---|
| 구름입력기가 목록에 없음 | 설치 후 로그아웃 안 함 → 로그아웃/재시동 |
| Shift+Space로 3개(ABC 포함)가 돌아감 | macOS 입력 소스 단축키가 켜져 있음 → 1-3 다시 |
| 영문 칠 때 `ㄸ` 같은 글자 | "한글 로마자"를 넣음 → 빼고 영어 목록의 "로마자" 추가 |
| 빠르게 칠 때 가끔 전환 누락 | macOS 한계. 구름 방식이 가장 나음(체감 9할 정상). ABC 선택하지 않기 |
| 원격에서 한/영 안 됨 | Karabiner 규칙/권한 확인, Windows에 AutoHotkey 스크립트 실행 중인지 확인 |
| 바탕화면에 Moonlight 디스크가 계속 생김 | dmg 안의 앱을 실행 중 → 2-2 다시 |
| Moonlight PIN 창에서 멈춤 | Windows `https://localhost:47990` → PIN 메뉴에서 입력 |

## 참고: 시행착오로 확인된 것 (다시 시도하지 말 것)

- **Mac 시스템 단축키에 Shift+Space 강제 지정(한영전환 앱)**: Shift를 누른 채로 Space 누르면 인식 안 됨
- **Karabiner로 입력기 직접 전환 (select_input_source)**: 전환이 느려서 빠르게 치면 글자 섞임
- **Karabiner Shift+Space → F18 → 시스템 단축키**: 동일하게 느리고 인식 더 나빠짐
- **Moonlight 코덱 H.265 수동 지정**: 4:4:4가 빠져서 글자 뭉개짐
