# 캡처 요청 목록 (새 컴퓨터 셋팅하면서 찍기)

> 셋팅 순서대로 진행하면서 **번호가 나오는 화면에서 한 장씩** 찍어주세요.
> 파일 이름을 번호로 바꿔서 주시면(예: `M03.png`) 매뉴얼 자리에 바로 넣습니다. 이름 바꾸기 귀찮으면 **올릴 때 번호만 적어줘도** 됩니다.
> ✅ 표시는 오늘 받은 스크린샷으로 이미 있는 것 → 안 찍어도 됨

**찍는 법**
- Mac 창 하나만: **Command+Shift+4 → 스페이스 → 창 클릭**
- 원격 Windows 화면: Moonlight를 **창 모드**(Control+Option+Shift+X)로 두고 위와 같이 Moonlight 창 클릭
- 이메일, IP 같은 개인정보는 신경 쓰지 말고 찍어주세요. 제가 가립니다.

---

## A. Windows (원격 대상 PC) — 먼저 진행

| 번호 | 단계 | 찍을 화면 |
|---|---|---|
| W01 | 설치 시작 | 압축 푼 폴더 (`install-Windows-v1.bat`, `setup.ps1` 보이게) |
| W02 | 설치 중 | 관리자 권한 확인 창 ("예" 버튼) |
| W03 | 설치 중 | SmartScreen 경고가 뜨면 그 창 (안 뜨면 생략) |
| W04 | 설치 완료 | 검은 설치 창의 마지막 "남은 수동 작업" 안내 화면 |
| W05 | Tailscale | 트레이 Tailscale 아이콘 눌렀을 때 로그인 화면 |
| W06 | Tailscale | 로그인 후 IP(`100.x.x.x`) 보이는 화면 |
| W07 | Sunshine | `localhost:47990` 접속 시 "연결이 비공개가 아님" 경고 화면 |
| W08 | Sunshine | 관리자 계정 만드는 첫 화면 |
| W09 | Sunshine | 로그인 후 메인 화면 (상단 메뉴 보이게) |
| W10 | 페어링 | **PIN 메뉴** 화면 (숫자 넣는 칸 보이게) — Mac M13 할 때 같이 |

> Windows 셋팅 자체는 원격 전이라 **그 PC 앞에서 Windows 키+Shift+S로 찍어도** 됩니다. W10은 페어링할 때라 원격/현장 아무거나.

## B. Mac — 한/영 (구름입력기)

| 번호 | 단계 | 찍을 화면 |
|---|---|---|
| M01 | 설치 | 구름입력기 다운로드 페이지 또는 pkg 설치 첫 화면 |
| M02 | 입력 소스 | 시스템 설정 → 키보드 화면 전체 ("편집..." 버튼, "키보드 단축키..." 버튼 보이게) |
| M03 | 입력 소스 추가 | **+** 눌러서 **한국어** 선택 → 구름 **두벌식** 보이는 목록 |
| M04 | 입력 소스 추가 | **+** 눌러서 **영어** 선택 → 구름 **로마자** 보이는 목록 |
| ✅ M05 | 입력 소스 완료 | ABC / 로마자 / 두벌식 + "문서의 입력 소스로 자동 전환" 꺼진 화면 |
| ✅ M06 | 단축키 창 | 키보드 단축키 창 (왼쪽 목록) |
| M07 | 단축키 끄기 | 왼쪽 **"입력 소스"** 선택 → 오른쪽 체크 **2개 끈 상태** |
| ✅ M08 | 구름 설정 | 구름 환경설정 창 |
| M09 | 구름 단축키 | "한글/로마자 바꾸기 단축키" 칸에 **⇧Space 들어간 상태** |
| M10 | 확인 | 메뉴 막대 입력 메뉴 펼친 화면 (구름 두벌식 선택된 상태) |

## C. Mac — 원격 (Moonlight + Karabiner)

| 번호 | 단계 | 찍을 화면 |
|---|---|---|
| ✅ M11 | Moonlight 설치 | DMG 창 (Moonlight → Applications) |
| M12 | Moonlight 설치 | 바탕화면 디스크 아이콘 **우클릭 → "추출"** 메뉴 보이는 상태 |
| M13 | 페어링 | Moonlight **+** 눌러 IP 입력하는 창 |
| M14 | 페어링 | Moonlight에 **PIN 4자리** 뜬 화면 |
| M15 | 접속 | 페어링 후 PC 아이콘 → "Desktop" 보이는 화면 |
| ✅ M16 | 화질 설정 | Moonlight 설정 화면 (1440p / 40Mbps / 코덱 자동 / 4:4:4) |
| M17 | Karabiner 설치 | 설치 중 **허용** 요청 화면 (시스템 설정 → 개인정보 보호 및 보안 쪽) |
| M18 | Karabiner 권한 | 입력 모니터링 목록에 Karabiner 켜진 화면 |
| M19 | Karabiner 규칙 | Complex Modifications → **Add your own rule** 화면 (붙여넣기 전/후 아무거나) |
| M20 | Karabiner 규칙 | 저장 후 규칙 목록에 "Moonlight + Chrome Remote" 보이는 화면 |
| M21 | 원격 한/영 확인 | Moonlight 창 안 Windows 메모장에서 한글 입력된 화면 (작업표시줄 "가" 보이게) |

## 요약

- 찍을 것: **Windows 10장 + Mac 16장 = 26장** (✅ 4장은 이미 있음)
- 못 찍은 건 비워두면 그 단계는 글로 설명합니다.
- 다 모이면 **"캡처 올림"** 하고 한꺼번에 주세요 → 설치파일 동봉 + 사진 매뉴얼(PDF)로 만들어 드립니다.
