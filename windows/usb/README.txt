PC설치 — 새 PC 를 한 번에 설정하는 USB 폴더 (github.com/devkhh002/dev-env)

1. Windows 를 설치한 뒤 이 폴더의 '시작하기.cmd' 를 두 번 누릅니다.
   - 인터넷이 없으면 '네트워크 드라이버' 폴더의 드라이버를 먼저 깝니다(이 PC 에 맞는 것만 들어갑니다).
   - 설치 화면이 뜨면 필요한 것을 체크하고 '선택한 것 설치' 를 누릅니다.

2. 네트워크 드라이버
   기종마다 랜(필요하면 Wi-Fi) 드라이버를 '네트워크 드라이버' 안에 폴더째 넣어 두세요.
   제조사 파일을 풀었을 때 .inf 파일이 들어 있는 폴더면 됩니다. 이 PC 에 맞지 않는 드라이버는 자동으로 건너뜁니다.

3. 도구
   인터넷 목록(winget)에 없는 프로그램은 '도구' 폴더에 넣고, GitHub 의 catalog.txt 에 한 줄 추가합니다.
   예)  도구 | 모두의 프린터 | usb:mo.exe | on
   .zip 은 C:\Tools\이름 에 풀리고, .exe·.msi 는 실행됩니다(설치 창은 직접 넘깁니다).

4. Remiz WSH (방화벽·디펜더·업데이트 등 윈도우 초기 설정)
   설치 화면의 'Remiz WSH 열기' 버튼이 '도구' 폴더의 'WSH by Remiz.cmd' 를 그대로 띄웁니다.
   이 도구는 'remiz' 폴더(dControl·Wub 등)가 옆에 있어야 동작합니다.
   디펜더가 켜져 있으면 dControl·Wub 를 HackTool 로 막아 복사가 안 되니,
   디펜더를 끈 뒤 'WSH by Remiz.cmd' 와 'remiz' 폴더를 '도구' 안에 넣어 두세요(WSH.iso 내용 그대로).

5. last-good 폴더
   마지막으로 잘 돌았던 설치 프로그램이 자동으로 저장됩니다. GitHub 에서 받지 못할 때 이것으로 엽니다. 지우지 마세요.
